# Fung Pleng

Version 1.0.0

Fung Pleng is a desktop music player for finding songs and listening to them in a continuous queue.

## What it can do

- Search YouTube for songs and start playback.
- Keep music going with related-song radio and an up-next queue.
- Mix tracks with DJ-style crossfades between songs.
- Create playlists, add songs, reorder tracks, and play a playlist in order or shuffle.
- Adjust playback volume and tune the sound with a seven-band equalizer.
- See recent listening history and get song suggestions based on what you play.

Fung Pleng uses an internet connection to search for and play music.
